# FlClash mihomo MRS 规则集

mihomo (`format: mrs` / 二进制) 格式的 Clash 规则集，由公开规则源
[blackmatrix7/ios_rule_script](https://github.com/blackmatrix7/ios_rule_script)
转换而来。

- 共 40 个文件：26 个 `domain` 规则集 + 14 个 `ipcidr` 规则集
- 用途：在 FlClash / mihomo 中作为 `rule-providers` 远程引用
- 本仓库**不包含任何代理节点、账号或密钥**

命名规则：`<规则集名>_D.mrs` 为域名类，`<规则集名>_I.mrs` 为 IP 类。
